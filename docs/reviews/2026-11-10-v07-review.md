## 4. 发现并修复的问题

1. **390px 横向溢出（677px）**：闭合 `<details>` 的子元素仍参与 Chromium 的 min-content 计算，`overflow-x:auto` 的表格容器挡不住祖先被撑宽。修复：`details:not([open])>.evidence-body, details:not([open])>.table-scroll { display:none }`，并给 flex 项加 `min-width:0`。
2. **SVG 图表在手机上文字过小**：680 宽 `viewBox` 缩到 324px 时 13px 字号实际约 6px。修复：改用 CSS 条形，标签保持真实像素并继承主题 token。
3. **深色主题图表配色**：原 SVG 把浅色 token 写进 `fill` 属性，暗色下会变成深字深底。改用 CSS 变量后暗色实测 `barFill rgb(183,201,237)` / `bg rgb(21,28,44)`。
4. **分享顺序与正文顺序不一致**：正文按决策顺序，分享弹层仍按发布顺序。修复：载荷增加 `decisionOrder`，弹层与复制文字同步，条目编号仍保持稳定。
5. **生成器 `mkdir` 报错**：本机路径代理不识别单独的 `exist_ok=True`，目录已存在时抛 `FileExistsError`。统一改为 `parents=True, exist_ok=True`。
