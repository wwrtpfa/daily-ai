# v0.5 UI 重构检查

本轮响应用户“重新设计 UI”的要求，重写站点布局与样式，保留 v0.4 的可用功能。没有使用外部站点模板、现成 UI 库或下载素材；流程图和标志为项目内 SVG/CSS。

## 视觉

- 1440×1000 桌面：固定深色侧栏、主线与原创图形、正文/目录分栏。
- 768×1024 平板：横向导航，正文完整宽度，辅助目录后置。
- 390×844 手机：专用横向流程图，首条标题位于约 693px，首屏可见正文开头，无横向溢出。
- 项目页：介绍网格与项目文字标识；本周：主题分组；往期：搜索与刊期网格；状态与分享同步改版。
- 五类页面、平板、手机、深色、分享的实际截图均已查看，保存在相邻 v05-assets 目录。

## 功能

实际操作通过：选单条分享、真实 PNG 下载、复制成功；项目周数据与主题筛选、指定项目原生展开；搜索 Agent 与无结果状态；深色主题切换。浏览器错误列表为空。

`python3 scripts/check-prototype.py`：12 页、506 个内部链接/片段、7 期内容完整性、RSS/日历和字节预算通过。`node --check prototype/app.js` 通过。

新闻和统计仍为演示；本轮没有接入生产采集、LLM 编纂或部署，也没有把静态预算检查写成 Lighthouse 或完整无障碍验收。新视觉是可体验方案，不表示用户已接受定稿。
